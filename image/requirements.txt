# What pip installs on the signer, pinned by CONTENT and not just by
# version. `pip install --require-hashes` refuses anything whose sha256
# does not match, so a compromised index or a hijacked release cannot
# hand this device a different wheel under the same version number.
#
# Bitcoin Core has been pinned this way since the beginning. These four
# were pinned by version only, which stops an accidental upgrade and
# stops nothing else (audit of image/, 2026-09-08).
#
# All four are pure Python (py3-none-any), so the wheel the Pi installs
# is byte-for-byte the wheel hashed here on the dev machine. Fetched with:
#   pip download --only-binary=:all: --platform manylinux2014_aarch64 \
#       --python-version 3.11 --implementation cp qrcode==7.4.2 pyzbar==0.1.9
#
# To change a version: re-run that, regenerate this file, and say in the
# commit why the version moved.
#
# --require-hashes needs EVERY package hashed, transitive ones included,
# which is why pypng and typing_extensions are here: qrcode pulls them.
